# DSH 截图插件 v2 — 需求与验收基线

本文是唯一的需求基线（由用户 2026-10-25 的任务书整理）。所有实现、验证、评审都以本文的 R 编号为准。
基线代码：仓库 `src/SnipTool.cs`（v1.0.5，4000 行，已可编译）+ `lib/client.js` / `lib/index.js`（DSH 插件两半）。
v1.0.5 已有能力（必须保留）：全屏截图覆盖层、拖拽选区、标注工具、颜色/粗细、撤销、保存/复制、暖进程（--serve）、中英文跟随、明暗跟随。

## A. 入口

- **R1** 输入框话筒按钮左侧新增截图按钮（剪刀图标），紧邻话筒左侧，尺寸/圆角/hover 与现有按钮一致；不能改变话筒自身行为。
- **R2** 点击该按钮进入截图模式（原生覆盖层）。
- **R3** 截图界面顶部有“隐藏 DSH 窗口”开关，默认勾选；其状态持久化，决定**后续**进入截图时是否最小化 DSH；开关本身不改变入口按键。
- **R4** 截图模式内单击鼠标右键退出截图模式（不产生截图）。
- **R5** 若进入截图模式时 DSH 被隐藏，退出（右键取消 / 取消按钮 / 确定完成）时都要恢复 DSH 窗口。

## B. 选区

- **R6** 进入后鼠标移动自动识别并高亮目标：指向应用窗口 → 该窗口区域；指向桌面空白 → 该屏幕完整区域；指向任务栏 → 任务栏区域。
- **R7** 屏幕尺寸不得写死（1920×1080 只是示例）：多显示器、每显示器 DPI 缩放、负坐标副屏都要正确。
- **R8** 候选选区用稍粗的蓝色边框（建议 2–3px，可随 DPI 缩放），左上角白底标签显示尺寸，如 `888×777`。
- **R9** 目标区域外变暗（半透明遮罩），区域内保持正常亮度。
- **R10** 单击确认自动识别的区域，直接进入编辑流程。
- **R11** 也可按住鼠标拖动手动框选：以按下位置为起点、松开位置为终点；拖动过程中实时显示边框与尺寸标签；松开即确认。
- **R12** 选区不能为 0 尺寸；极小选区（<3px）视为误触，回到待选区状态。

## C. 截图设置与长截图

- **R13** 截图界面顶部显示开关栏：左侧“隐藏 DSH 窗口”（默认勾选），右侧“长截图”。
- **R14** 长截图模式：先选择区域（R10/R11 任一方式），然后在该区域内滚动鼠标滚轮，捕获并拼接滚动内容；滚轮向上应停止扩展或回退到已捕获范围（不允许重复拼接）。
- **R15** 长截图时在选区旁边显示预览图，内容变长时预览按比例缩小（高度受限于屏幕，宽度等比），并实时更新。
- **R16** 长截图结束（点击完成/确定，或按 Enter）后进入与普通截图相同的编辑流程。
- **R17** 取消或完成截图时合理恢复 DSH 窗口（与 R5 一致）。

## D. 编辑与完成

- **R18** 普通截图和长截图进入同一编辑流程（同一编辑器、同一工具栏）。
- **R19** 截图下方显示纯图标工具栏，悬停显示文字提示（中文/英文跟随 DSH）。
- **R20** 左侧工具：简单图形（矩形/椭圆/直线）、箭头、画笔、文本；可调整颜色与粗细。
- **R21** 中间：马赛克。
- **R22** 右侧：保存、取消（红叉）、确定（绿勾）。
- **R23** 确定后把最终图片加入 DSH 会话输入区（附件），**不自动发送**。
- **R24** 保存 = 保存 PNG 到磁盘；取消 = 放弃并恢复 DSH。

## E. 工程约束

- **R25** 作为 DSH 插件可安装到桌面 profile（`~/.dsh/profiles/desktop/package.json` 的 dependencies + `dsh.profile.bundles`，以及 `cordis.patch.yml`）。
- **R26** 原生 exe 用 .NET Framework 4.8 + `csc.exe` 构建（无额外运行时依赖），不弹 CLR 崩溃对话框，崩溃写日志。
- **R27** 保留单实例 + 暖进程机制（`--serve`），二次点击快速响应。
- **R28** 语言跟随 DSH（中/英），明暗主题跟随 DSH。
- **R29** 完全本地，无网络请求。
- **R30** 必须能给出可复现证据：无头自测模式输出 PNG + JSON（见 docs/INTERFACES.md 的证据协议）。

## 非目标

- 不做云上传、不做 OCR、不做录屏/视频。
- 不改 DSH 主程序（`resources/app`），只做外部插件。
- 不自动重启用户的 DSH 桌面进程（安装脚本只做准备，重启由用户执行）。
